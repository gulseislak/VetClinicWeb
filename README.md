# Veterinary Clinic Management System

A database systems project developed for the **CMPE 232 – Database Systems** course at TED University. The project focuses on designing a relational database structure for managing veterinary clinic operations.

## Project Overview

The proposed database design covers the main entities and relationships required for a veterinary clinic management system, including pet owners, animals, veterinarians, appointments, diagnoses, treatments, invoices, and invoice items.

The project emphasizes relational database design, data integrity, and the organization of clinic-related information.

## Database Design

The proposed database structure includes:

- **Owners:** Pet owner information
- **Animals:** Information about animals registered at the clinic
- **Veterinarians:** Veterinarian records
- **Appointments:** Appointment-related information
- **Diagnoses:** Diagnosis records
- **Treatments:** Treatment-related information
- **Invoices:** Billing records
- **Invoice Items:** Individual items associated with invoices

The design defines relationships between entities and considers integrity constraints to support consistent data organization.

## Technologies
